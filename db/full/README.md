## How `listed_check` works

- `TO_CONFIRM`: the date is a best public value that no one has checked against a primary page. For a stock it is review-only. The binding test for "listed before 2007-01" is measurable: a month-end close for 2006-12 in the canonical source (`has_2006_12 = Y`), written by the sweep (PLAN §13-7).
- `CONFIRMED`: checked against a public page and recorded. An ETF's `listed_on` drives the proxy months of the history (H7), so every pool ETF must be `CONFIRMED` from its issuer page before approval.

## Availability and approval flow

1. **02-A:** candidates, rule, groups. Availability columns stay empty.
2. **Sweep:** the KIS monthly sweep fills `kis_excd`, `kis_first_month`, `yf_first_month`, `has_2006_12` for all 216 candidates (no price is stored).
3. **02-B (this PR):** `status` is set. A candidate that fails a check (no 2006-12 close, a gap in the main period from 2007-01, a rejected symbol) is `FAILED_CHECK` and the next candidate by `rule_rank` takes its place. The first 50 / 100 / 30 rows that pass are `SELECTED`; the rest are `RESERVE`. `asset.csv`, `asset_group.csv` and `fetch_targets.csv` are generated from the selection.
4. **Owner approval:** the owner reads the 02-B PR. A row-level change is made through `owner_decision` (`DROP` / `KEEP`) or a review comment. **Merging the 02-B PR is the pool approval.**

## Proxy map (MVP-03 A)

A month in which an asset has no actual return is filled from a public series. `proxy_series.csv` lists the series, `proxy_map.csv` gives every pool asset an ordered fallback list (a ladder), and `python3 tools/fetch/proxy_map.py check --strict` is the gate the build runs first: any (asset, month) cell from 1996-01 to 2025-12 that has no actual return and no covering series stops the build, and so does a stock without an actual return in any month from 2007-01.

**Rules.**
- `first_month` of a row = the first month the series can give a return (two consecutive observations), clipped to 1996-01; a yield input (`basis = RATE`) gives its first month-end level, clipped to 1995-12. `last_month` is clipped to 2025-12 (the history end). `RATE` rows feed `DERIVED` rows only; the map may not name them.
- An asset's first actual return month is the month after its first month-end close: the measured first month (KIS monthly bars for KR, yfinance for US stocks) or, where no yfinance file exists yet, the listing month (`LISTING`). Per missing month the lowest `priority` series that covers the month wins (`proxy_map.csv`, `to_krw`: multiply by 1 + `fx_change`; `fee_applied`: ETFs only, fee/12 subtracted in proxy months only, PLAN §4.6).
- `to_krw = Y` exactly when a USD series fills a won asset, except a hedged ETF (name contains `(H)`: KODEX WTI crude). `ASSET` rows use the pool asset's own actual returns only.
- Awaiting measurement: 16 KR ETFs and 23 KR stocks take their first month from the KIS monthly sweep (final unless the daily drip starts later); 18 US stocks from yfinance files; **13 US ETFs and `BRK.B` take it from the listing date and wait for the yfinance run** (the check must be re-run after it).

**Derived formulas** (reference implementation `tools/fetch/derived.py`; the build SQL must match it). Yields are percent in the files: divide by 100. `y_{t-1}`, `y_t` are the previous and the current month-end yield.
- `PAR_BOND_TR(yield, N)`: a constant-maturity bond of N years whose semiannual coupon equals `y_{t-1}`, repriced exactly at `y_t`: `r = y_{t-1}/12 + (c·(1-(1+j)^-n)/j + (1+j)^-n - 1)`, with `j = y_t/2`, `c = y_{t-1}/2`, `n = 2N` (when `j = 0` the annuity is `n`). Carry, duration, convexity and higher terms are all inside the repricing; no duration constant, no roll-down. Example: N = 10, 5.00 % → 6.00 % gives `-0.07022071` (carry +0.4167 %, price effect -7.44 %).
- `CASH_ACCRUAL(yield)`: `r = y_{t-1}/12`, no price effect.
- `MIX_50_50(a, b)`: `0.5·a + 0.5·b`, rebalanced every month.
- `MIX_W(a, b, w)`: `w` % of `a` and the rest of `b`, rebalanced every month (`w` is a whole percent in the formula text).
- `MIX_50_50_FX(usd_leg, krw_leg)`: `0.5·((1 + a)(1 + fx_change) - 1) + 0.5·b`; only the USD leg is converted, so the map row has `to_krw = N`.
- ETF proxy months: `r_etf = r_proxy - annual_fee/12` after `to_krw` is applied once: `(1 + r)(1 + fx_change) - 1`. Stocks never get a fee deduction.

## `listed_check`의 뜻

- `TO_CONFIRM`: 아직 1차 페이지로 확인하지 않은 공개 값이다. 주식에서는 검토용이다. "2007-01 이전 상장"의 구속력 있는 검사는 측정 가능한 형태로 훑기가 적는다: 정본 출처의 2006-12 월말 종가(`has_2006_12 = Y`, PLAN §13-7).
- `CONFIRMED`: 공개 페이지로 확인하고 기록했다. ETF의 `listed_on`은 이력의 대체 달(H7)을 정하므로, 풀의 모든 ETF는 승인 전에 운용사 페이지로 `CONFIRMED`가 돼야 한다.

## 대체 대응표 (MVP-03 A)

실제 수익률이 없는 달은 공개 시리즈로 채운다. `proxy_series.csv`가 시리즈 목록, `proxy_map.csv`가 종목마다 순서가 있는 대체 목록(사다리)이고, `python3 tools/fetch/proxy_map.py check --strict`가 빌드가 가장 먼저 도는 관문이다. 1996-01–2025-12 중 실제 수익률도 덮는 시리즈도 없는 (종목, 달) 칸이 하나라도 있으면 빌드가 멈추고, 2007-01 이후 어느 달이든 실제 수익률이 없는 개별 주식이 있어도 멈춘다.

**규칙.**
- 시리즈 행의 `first_month`는 수익률을 낼 수 있는 첫 달(연속 관측 2개 필요, 1996-01로 자름)이고, 금리 입력(`basis = RATE`)은 월말 수준의 첫 달(1995-12로 자름)이다. `last_month`는 2025-12(이력의 끝)로 자른다. `RATE` 행은 `DERIVED` 행의 입력으로만 쓰이고 대응표가 직접 이름을 쓸 수 없다.
- 종목의 첫 실제 수익률 달은 첫 월말 종가가 있는 달의 다음 달이다. 측정된 첫 달(국내는 KIS 월봉, 미국 주식은 yfinance)을 쓰고, 아직 yfinance 파일이 없으면 상장 월(`LISTING`)을 쓴다. 비어 있는 달마다 그 달을 덮는 시리즈 중 `priority`가 가장 낮은 것이 이긴다(`to_krw`: (1 + `fx_change`)를 곱함, `fee_applied`: ETF만, 보수/12는 대체 달에서만 뺀다 — PLAN §4.6).

**파생 공식**(기준 구현 `tools/fetch/derived.py`, 빌드 SQL은 이와 같아야 한다). 파일의 금리는 퍼센트이므로 100으로 나눈다. `y_{t-1}`, `y_t`는 전월 말·당월 말 금리다.
- `PAR_BOND_TR(금리, N)`: 반기 쿠폰이 `y_{t-1}`인 N년 만기 일정 만기 채권을 `y_t`로 정확히 다시 평가한다: `r = y_{t-1}/12 + (c·(1-(1+j)^-n)/j + (1+j)^-n - 1)`, `j = y_t/2`, `c = y_{t-1}/2`, `n = 2N`(`j = 0`이면 연금 계수는 `n`). 이자, 듀레이션, 볼록성, 고차 항이 모두 재평가 안에 들어 있어 듀레이션 상수도 롤다운도 없다. 예: N = 10, 5.00 % → 6.00 %는 `-0.07022071`(이자 +0.4167 %, 가격 효과 -7.44 %).
- `CASH_ACCRUAL(금리)`: `r = y_{t-1}/12`, 가격 효과 없음.
- `MIX_50_50(a, b)`: `0.5·a + 0.5·b`, 매달 재조정.
- `MIX_W(a, b, w)`: `a`를 `w` %, 나머지를 `b`로 섞고 매달 재조정한다(공식 문자열의 `w`는 정수 퍼센트).
- `MIX_50_50_FX(달러 구간, 원화 구간)`: `0.5·((1 + a)(1 + fx_change) - 1) + 0.5·b`. 달러 구간만 환산하므로 대응표 행은 `to_krw = N`이다.
- ETF 대체 달: `to_krw`를 한 번만 적용한 뒤(`(1 + r)(1 + fx_change) - 1`) `r_etf = r_proxy - annual_fee/12`. 개별 주식은 보수를 빼지 않는다.
